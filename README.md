# Programming Lab I - Maze

## このRepositoryについて

このrepositoryは、Programming Lab Iの共通Baseline Projectです。
15回の授業を通して、同じMaze programを少しずつ育てていきます。

> Mazeを学ぶことが目的ではありません。
> Mazeを使ってProgrammingを学びます。

Week 1は、小さなPython programを

**Run → Read → Change → Commit**

するところから始めます。

その後、このprogramを
object-oriented design、data structures、algorithms、modules/packages、
testing、Git/GitHub collaboration、CI、Release
へと段階的に発展させていきます。

## 実行方法

Python 3が必要です（外部packageは使用しません）。

```bash
cd programming-lab-maze
python starter.py
```

環境によっては `python` の代わりに `python3` を使ってください。

## 操作方法

| Key | 動作 |
| --- | --- |
| `W` | 上へ移動 |
| `S` | 下へ移動 |
| `A` | 左へ移動 |
| `D` | 右へ移動 |
| `Q` | 終了 |

大文字・小文字のどちらでも入力できます。入力後にEnterを押してください。

表示の意味：`#` = Wall、`P` = Player、`G` = Goal、空白 = Path
